# Data and provenance

The repository publishes processed catalogue inputs, derived photometry, model inputs and archive manifests. Original Herschel, ALMA, SCUBA and other survey products remain hosted by their official archives and are not republished here.

`archive_manifest.json` and the source manifests identify the archive/project provenance. `processed/` contains the exact tabular inputs used by the frozen release. `checksums.sha256` is generated for the release files.

Third-party data retain their original licences and attribution requirements. The repository's MIT licence applies only to original code and documentation.
