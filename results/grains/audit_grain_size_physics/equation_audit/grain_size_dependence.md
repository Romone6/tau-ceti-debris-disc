# Grain-size dependence

For q=11/6, `5 - 3q = -1/2`. Thus Eq. 14 has f_max ∝ D_cut^(-1/2), and f/f_max ∝ D_cut^(+1/2).

If the physical derivation uses D_bl but the empirical lower cutoff is D_min, the generalized conversion is

`f_max(D_min) = f_max(D_bl) * (D_min/D_bl)^(-1/2)`

This is a reparameterisation only if D_min is explicitly declared the cascade cutoff. Directly relabelling an observational minimum as D_bl is not physically justified. q=11/6 corresponds to the adopted differential size-distribution slope p=3q-2=3.5, so cross-sectional area scales as D_min^(3-p)=D_min^(-0.5).
