# Parameter dictionary

- `f_tau`: Tau Ceti fractional dust luminosity.
- `q_tau`: posterior predictive percentile of Tau Ceti within the comparison population.
- `z_tau`: standardized posterior predictive residual.
- `D_bl`: radiation-pressure blowout diameter; a derived scenario quantity.
- `D_min`: physical minimum grain size or fixed sensitivity value; not interchangeable with `D_bl`.
- `D_c`: largest body participating in the collisional cascade.
- `Q_D*`: catastrophic disruption energy in J kg⁻¹.
- `e`, `I`: mean planetesimal eccentricity and inclination; the reference collisional run uses `I=e`.
- `R_in`, `R_out`: belt inner and outer radii in AU.

See the YAML configuration files for distributions, bounds and source rationale.
